# IQ Center — лендинг пробных ЕГЭ/ОГЭ

Next.js 15 + React + Tailwind CSS 4 + Framer Motion. Сайт собирается в статические файлы (`out/`).

## Команды

```bash
npm install        # один раз
npm run dev        # разработка: http://localhost:3000 (форма здесь не отправляется — нет PHP)
npm run build      # сборка в папку out/
npm start          # проверить собранный сайт с PHP: http://127.0.0.1:8000
```
