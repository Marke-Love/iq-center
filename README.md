# IQ Center — лендинг пробных ЕГЭ/ОГЭ

Next.js 15 + React + Tailwind CSS 4 + Framer Motion. Сайт собирается в статические файлы (`out/`) и работает на обычном хостинге reg.ru. Заявки отправляет `send.php` в Telegram и на почту.

## Команды

```bash
npm install        # один раз
npm run dev        # разработка: http://localhost:3000 (форма здесь не отправляется — нет PHP)
npm run build      # сборка в папку out/
npm start          # проверить собранный сайт с PHP: http://127.0.0.1:8000
```

## Где что менять

Все тексты-данные — в **`src/content/site.ts`**: телефон, адрес, реквизиты, цены, предметы, эксперты, отзывы, FAQ, ID Метрики. После правки — `npm run build` и перезалить `out/`.

## Перед запуском рекламы в Директе — обязательно

- [ ] **Реквизиты** ИП/ООО (`legal` в site.ts) — без них модерация Директа не пропустит.
- [ ] **Домен** (`url` в site.ts и строка `Sitemap:` в `public/robots.txt`).
- [ ] **Цены** (`plans[].price`). Пока цена `null`, показывается «Стоимость по телефону».
- [ ] **Отзывы и эксперты** — сейчас это заглушки. Выдуманные отзывы и результаты публиковать нельзя (закон о рекламе, модерация Директа). Используйте реальные, с согласия учеников.
- [ ] Проверьте формулировки о процессе («перезвоним за 15 минут», «результаты за 3 дня», «пробники по выходным») — должны соответствовать реальности.
- [ ] Текст политики ПД (`src/app/privacy/page.tsx`) — лучше показать юристу. Если обрабатываете ПД, подайте уведомление в Роскомнадзор.
- [ ] Email и ссылка на Telegram (`email`, `telegram`).
- [ ] OG-картинка для соцсетей: положите `public/og.png` (1200×630) и добавьте `images: ["/og.png"]` в `openGraph` в `src/app/layout.tsx`.

## Яндекс.Метрика

1. Создайте счётчик на metrika.yandex.ru, впишите номер в `metrikaId`.
2. Создайте цели типа «JavaScript-событие» с идентификаторами:
   `form_submit` (главная — заявка), `click_phone`, `click_cta`, `open_modal`, `subject_click`, `click_messenger`.
   Дополнительно цель «Посещение страниц» — URL содержит `/thanks/`.
3. В Директе включите оптимизацию по цели `form_submit`.

UTM-метки и `yclid` сохраняются и приходят в каждой заявке — видно, с какого объявления лид.

## Заявки: Telegram + Email

1. В Telegram напишите @BotFather → `/newbot` → получите токен.
2. Добавьте бота в нужный чат/группу, отправьте туда любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — возьмите `chat.id`.
3. На хостинге рядом с `send.php` создайте `config.php` по образцу `config.example.php` и впишите токен, chat_id и почту.
   `config.php` не хранится в git и закрыт от доступа через `.htaccess`.
4. Для почты лучше создать ящик на своём домене в панели reg.ru и указать его в `email_from` — так письма не попадут в спам.

## Заливка на reg.ru

1. `npm run build`.
2. В панели reg.ru → Хостинг → Менеджер файлов (или FTP) откройте папку сайта `www/ваш-домен/` (или `public_html`).
3. Загрузите **содержимое** папки `out/` (не саму папку), включая скрытый `.htaccess`.
4. Создайте там же `config.php` (см. выше).
5. Подключите бесплатный SSL (Let's Encrypt) в панели reg.ru — `.htaccess` сам перенаправит на https.
6. Отправьте тестовую заявку и проверьте Telegram и почту.
